# Legion Mark-II 3D Files

These STL files represent the mechanical platform used for the Legion Mark-II project.

## Attribution

The base mechanical design was derived from a publicly available design by New Era Exploration and was used as a starting point for the Legion platform.

The Legion Mark-II project involved project-specific integration and modifications, including the N20 wheel-drive configuration, electronics, control system, sensing, and ESP32-CAM monitoring.

The original design source should be consulted for the original mechanical design and its applicable terms of use.
