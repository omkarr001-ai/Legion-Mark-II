# Legion Mark-II

### Hybrid Quadruped & Wheeled Exploration Robot

Legion Mark-II is a hybrid robotic platform designed for exploration of difficult and disaster-prone environments. It combines quadruped locomotion with wheeled driving, along with embedded control, obstacle sensing, and live visual monitoring.

## 🚀 Key Features

- 12-servo quadruped locomotion
- N20 motor-driven wheels for driving mode
- Ultrasonic-based obstacle detection
- ESP32-CAM for live visual monitoring
- WebSocket-based control and monitoring interface
- Arduino Nano-based main control system
- PCA9685 16-channel servo driver

## 🔧 Hardware

- Arduino Nano
- ESP32-CAM
- PCA9685 Servo Driver
- 12 × Servo Motors
- N20 Geared DC Motors
- Ultrasonic Sensor
- 18650 Battery Cells
- Buck Converter

## 💻 Software

- Arduino IDE
- Embedded C/C++
- WebSocket-based communication
- ESP32-CAM web interface
